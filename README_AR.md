# SALEM TradingView Signal Bridge — دليل التشغيل بالعربية

هذه الحزمة تضيف استقبالًا فعليًا لإشارات TradingView إلى واجهة SALEM V3. **يجب نشرها على عنوان HTTPS عام** حتى تستطيع TradingView إرسال Webhook إليها. فتح HTML من الجهاز وحده لا يكفي لاستقبال Webhooks.

## ما الذي تفعله الحزمة؟
- تعرض واجهة SALEM وTradingView Advanced Chart.
- تستقبل إشارات JSON من Pine Script عند `/webhook`.
- تعرض أحدث 300 إشارة في لوحة «إشارات TradingView» وتحدّثها كل 5 ثوانٍ.
- تدعم CALL / PUT / WAIT، والرمز والسعر والفريم والدرجة واسم المؤشر.
- تحتوي على زر إشارة اختبار لاختبار الاستقبال قبل ربط المؤشر.
- **لا** ترسل أوامر شراء أو بيع، ولا تربط IBKR في هذه المرحلة.

> البطاقات القديمة أعلى V3 ما زالت بيانات توضيحية. سجل «إشارات TradingView» فقط يعرض الإشارات التي تصل عبر Webhook بالفعل.

## النشر على Render بأقل خطوات

1. فك ضغط ZIP.
2. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا **Private**.
3. داخل المستودع اضغط **Add file → Upload files**، وارفع محتويات المجلد كما هي (لا ترفع ملف ZIP فقط). يجب أن يكون `render.yaml` في جذر المستودع، وأن يكون HTML في `static/index.html`.
4. افتح Render وأنشئ **New → Blueprint**، ثم اربطه بالمستودع. وافق على إنشاء خدمة `salem-tradingview-bridge`. ملف `render.yaml` يضبط خدمة Python والاعتماديات وينشئ `WEBHOOK_SECRET` عشوائيًا.
5. بعد اكتمال النشر، افتح صفحة الخدمة في Render ثم **Environment**. اعرض قيمة `WEBHOOK_SECRET` وانسخها لنفسك فقط؛ لا ترسلها لي ولا تنشرها في المستودع.
6. افتح رابط الخدمة الذي ينتهي بـ `onrender.com`. في قسم «ربط إشارات TradingView» ألصق السر في خانة Webhook Secret واضغط «إنشاء رابط Webhook» ثم «نسخ الرابط».
7. اضغط «إرسال إشارة اختبار». يجب أن تظهر إشارة `TEST` في الجدول. إذا لم تظهر، تأكد أن السر في الواجهة يطابق قيمة Render حرفيًا.

## ربط TradingView

1. افتح TradingView على الشارت المطلوب.
2. افتح Pine Editor، ثم افتح الملف `SALEM_TV_Webhook_Template.pine` وانسخ كوده إلى محرر Pine (أو افتح ملف Pine محليًا وانسخه). اضغط **Save** ثم **Add to chart**.
3. أنشئ Alert واختر مؤشر `SALEM TradingView Webhook Bridge - Example`، ثم اختر **Any alert() function call**.
4. فعّل **Webhook URL** والصق الرابط الذي نسخته من SALEM. لا تضع كلمة المرور أو أي API key داخل رسالة التنبيه.
5. أنشئ التنبيه. سيُرسل المثال CALL/PUT عند تقاطع EMA 20 وEMA 50 عند إغلاق الشمعة.

## كيف أرسل إشارات مؤشري الحالي بدل EMA؟

ملف Pine المرفق مثال مستقل فقط. لكي ترسل إشارات مؤشرك الفعلية، افتح مصدر المؤشر الذي تملكه أو تستطيع تعديله، واستبدل `buySignal` و`sellSignal` في المثال بشروط الشراء والبيع الحقيقية من ذلك المؤشر، ثم أضف كتل `if ... alert(payload, alert.freq_once_per_bar_close)` في نهايته. لا يمكن للجسر قراءة متغيرات داخل سكربت آخر تلقائيًا ما لم يكن المؤشر نفسه يرسل تنبيهات.

إذا كان المؤشر الحالي يملك بالفعل تنبيهات مناسبة، تستطيع استخدام تنبيهاته الموجودة لكن ينبغي أن تكون رسالة التنبيه JSON بالحقول المتوقعة، مثل:

```json
{"indicator":"My Pine Indicator","symbol":"{{ticker}}","exchange":"{{exchange}}","action":"CALL","price":{{close}},"timeframe":"{{interval}}","score":85}
```

قد تحتاج رسالة منفصلة لـ PUT حسب شرط المؤشر. لا تضف سر الجسر داخل جسم JSON؛ السر يكون في رابط Webhook فقط.

## متطلبات وأمان وحدود
- يتطلب TradingView تفعيل المصادقة الثنائية (2FA) لاستخدام Webhooks. عنوان Webhook يجب أن يكون HTTPS عامًّا؛ TradingView يقبل المنافذ 80 و443 ويلغي الطلب إذا استغرق الخادم أكثر من 3 ثوانٍ. لذلك يستجيب هذا الخادم بسرعة ويحفظ الإشارة في الذاكرة.
- احتفظ بالمستودع Private، ولا تنشر `WEBHOOK_SECRET`. هذا السر مخصص لاستقبال التنبيهات وليس مفتاح وسيط.
- الخطة المجانية على Render قد توقف الخدمة بعد الخمول، وقد تفقد الإشارات المخزنة في الذاكرة عند إعادة التشغيل أو السكون. هذه النسخة للاختبار؛ للإنتاج نضيف قاعدة بيانات ثابتة ومصادقة مستخدمين ومراقبة.
- لا تتعامل مع CALL/PUT أو Score كتوصية مضمونة. مؤشر المثال مجرد EMA crossover توضيحي، ودرجة 80/20 في المثال ثابتة لإظهار نقل الحقول وليست مقياس ثقة محسوبًا.


## إضافة جاهزة لمؤشر RedK MMTStop الذي تعمل عليه

في محرر Pine افتح نسخة المؤشر التي تملك مصدرها، والصق المقطع الموجود في الملف `RedK_MMTStop_Webhook_Patch.txt` في نهاية الكود ثم اضغط Save وAdd to chart. يعتمد هذا المقطع على المتغيرين `flipUp` و`flipDn` الموجودين في النسخة الحالية من RedK MMTStop التي راجعناها سابقًا. إذا كانت أسماء المتغيرات مختلفة في نسختك، يجب تعديلها لتطابق اسم شرط الإشارة.
